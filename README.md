Gift Genie is a Streamlit web application that collects information about a person, budget, and occasion from the user. It passes that information to an OpenAI model through the Responses API. The model can use web search to find current product information and is instructed to return five personalized recommendations. Pydantic provides a structured format for those recommendations so the Python application can reliably access each gift's name, reason, and price. Streamlit then displays those recommendations to the user.
